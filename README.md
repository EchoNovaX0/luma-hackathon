# 🦴 CNN Trained on GAN-Generated Dataset for Bone X-ray Analysis

A Convolutional Neural Network (CNN) trained on a **synthetic dataset generated by a GAN** to learn hierarchical visual features from bone/X-ray style images (edges → structure → subtle abnormalities).

> ⚠️ **Disclaimer:** This project is for research and educational purposes only. It is **not** a medical diagnostic tool.

## Overview
Real medical datasets are often scarce, imbalanced, and privacy-restricted. To address this, a **GAN (Generative Adversarial Network)** was used to generate synthetic images, and a **CNN** was trained on this data to classify them.

## Project Pipeline
```
Real Images → GAN Training → Synthetic Dataset → Preprocessing → CNN Training → Evaluation → Prediction
```

## What Each Layer Learns
The network learns features **hierarchically**, from simple to complex:

### 1️⃣ Shallow Layers – Basic Patterns
- Basic lines and borders
- Light vs. dark regions
- Bone edges, joint outlines, fracture-like lines

### 2️⃣ Middle Layers – Structural Patterns
- Thickness of structures
- Hollow vs. dense areas
- Alignment of bones
- Slight textures

### 3️⃣ Deep Layers – Fine, Abstract Patterns
- Slight irregularities
- Texture changes
- Shape changes

| Depth | Learns | Example |
|---|---|---|
| Shallow | Edges, contrast | Bone outline |
| Middle | Thickness, density, alignment | Hollow vs. dense bone |
| Deep | Irregularities, texture/shape changes | Hairline fracture patterns |

## Activation & Loss Functions
| Task | Output Activation | Loss Function |
|---|---|---|
| Binary classification | **Sigmoid** | **Binary Cross-Entropy** |
| Multi-class classification | **Softmax** | **Categorical Cross-Entropy** |

- **Sigmoid** outputs a probability between 0 and 1 for a single class.
- **Softmax** outputs a probability distribution across multiple classes (sums to 1).
- Hidden layers use **ReLU** for fast, stable training.

```bash

# 2. Train the CNN

# 3. Evaluate
python evaluate.py

# 4. Predict
python predict.py --image path/to/image.png
```

**Sample code**
```python
from tensorflow.keras import layers, models

model = models.Sequential([
    layers.Conv2D(32, 3, activation='relu', input_shape=(128,128,1)),
    layers.MaxPooling2D(),
    layers.Conv2D(64, 3, activation='relu'),
    layers.MaxPooling2D(),
    layers.Conv2D(128, 3, activation='relu'),
    layers.MaxPooling2D(),
    layers.Conv2D(256, 3, activation='relu'),
    layers.MaxPooling2D(),
    layers.Flatten(),
    layers.Dense(128, activation='relu'),
    layers.Dropout(0.5),
    layers.Dense(1, activation='sigmoid')   # Softmax for multi-class
])

model.compile(optimizer='adam',
              loss='binary_crossentropy',   # categorical_crossentropy for multi-class
              metrics=['accuracy'])
```
